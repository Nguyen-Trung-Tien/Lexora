# Lexora v1.4.0 — Semantic Knowledge Graph & Homophones Center
> Release Date: 2026-10-27 | Version: 1.4.0

## 🌟 Highlights
Lexora v1.4.0 debuts the **Semantic Knowledge Graph** for visual vocabulary exploration and the **Homophones Center** for distinguishing confusing sound-alike word pairs, complemented by a high-speed Smart Import wizard.

---

## 🚀 New Features
- **Vocabulary Knowledge Graph**: Visualizes semantic connections between words through topic clusters, synonyms, antonyms, and word families, enhancing contextual recall.
- **Homophones Learning Center**: Curated directory of identically pronounced words with different meanings and spellings (e.g., *sea / see*, *knight / night*), featuring audio comparisons and contrastive sample sentences.
- **Smart Batch Import (CSV/JSON)**: Import large vocabularies and grammar decks with automatic deduplication against existing database entries.

---

## ⚡ Improvements & UX
- **Typo-Tolerant Smart Search**: Suggests relevant vocabulary matches even when words are slightly misspelled.
- **Streamlined Navigation Layout**: Reorganized specialized study tools into intuitive, easily accessible navigation items.
