# Lexora v1.6.2 — Smart Import Resilience & UI Stability Patch
> Release Date: 2026-11-14 | Version: 1.6.2

## 🌟 Highlights
Lexora v1.6.2 delivers a major stability and resilience patch for **Smart Data Import**, resolving native application teardown crashes upon import completion, automating SQLite tag deduplication, and streamlining post-import library refreshes.

---

## 🚀 New Features
- **Resilient Multi-Format Smart Parser**: Automatically recognizes TSV, CSV, Colon-separated, Hyphen-separated, and AI-generated vocabulary and grammar lists with flexible column detection and intelligent fallback mappings.
- **Atomic Batch Upsert & Tag Auto-Healing**: Safely handles duplicate entries within batch payloads and auto-heals pre-existing duplicate exam/topic tags in SQLite without throwing key collision exceptions.

---

## ⚡ Improvements & UX
- **Seamless Dialog Teardown & Chaining**: Hardened `SafeDialogExtensions` with guaranteed visual tree popup detachment delays (80ms), completely preventing WinUI 3 focus and compositor race conditions.
- **Double-Click Protection on Import Actions**: Primary actions and completion buttons ("Done / Hoàn tất") automatically guard against re-entrant clicks with instantaneous state locking.
- **Safe Post-Import UI Refresh**: Replaced hazardous manual binding tree updates with native `INotifyPropertyChanged` and `INotifyCollectionChanged` notifications for instant, flicker-free word list refreshes.

---

## 🛠️ Bug Fixes & Stability
- **Resolved Post-Import Native Crash (0xc0000005)**: Fixed an Access Violation in `Microsoft.UI.Xaml.dll` triggered when dismissing `SmartImportDialog` and reloading large vocabulary lists simultaneously.
- **Fixed Exam Tag Dictionary Key Collision**: Eliminated `ArgumentException: An item with the same key has already been added` during batch imports when the database contained case-variant or duplicated exam tags.
- **Unloaded Lifecycle Hardening**: Secured `SmartImportDialog.Unloaded` lifecycle routines with defensive exception handling and null reference guards to avoid cross-boundary ABI faults.

---

## 🇬🇧 English Summary
Lexora v1.6.2 resolves a native WinUI 3 access violation when completing Smart Imports, adds database deduplication for exam tags, and ensures fast, crash-proof vocabulary and grammar imports.
