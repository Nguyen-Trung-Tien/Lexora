# Lexora v1.6.1 — Interactive Fluent 2 Roadmap & System Polish
> Release Date: 2026-11-05 | Version: 1.6.1

## 🌟 Highlights
Lexora v1.6.1 introduces a redesigned **Fluent 2 Interactive Learning Pathway**, next-generation **FSRS v5 spaced repetition**, dynamic multi-word homophone comparison, and a 95% reduction in memory footprint when loading study roadmaps.

---

## 🚀 New Features
- **Interactive Fluent 2 Learning Pathway**: A visual, milestone-driven study road for TOEIC, IELTS, and VSTEP exam preparation. Track Phase progress, review required vocabulary and grammar units, and automatically unlock downstream checkpoints as you master each node.
- **FSRS v5 Spaced Repetition Engine**: Integrates memory *Stability* and *Difficulty* tracking into the review scheduler, providing optimal review intervals with fewer redundant repetitions.
- **Multi-Word Homophone Groups**: Compare three or more identically pronounced words simultaneously (e.g., *there / their / they're*), complete with definitions, phonetic transcriptions, and contextual examples.
- **Smart Adaptive Quiz Navigation**: The test navigation button automatically transforms into *"Finish Test"* with a checkmark icon on the final question, ensuring test-takers submit with confidence without lost scores.

---

## ⚡ Improvements & UX
- **95% Memory Allocation Reduction**: Database counting and node progress calculations are now processed directly inside SQLite, enabling instant page transitions on low-spec hardware.
- **Standardized Segoe Fluent Iconography**: Unified crisp, branded icons across Learning Storage, Vocabulary, Grammar, Review, and Test pages.
- **Real-World Ebbinghaus Retention Curve**: Memory decay charts in the Statistics module now reflect real user study logs rather than rigid theoretical approximations.

---

## 🛠️ Bug Fixes & Stability
- **Resolved Roadmap Action Lockup**: Fixed an occasional UI freeze when clicking "Advance Progress (+25%)" or "Mark Completed" repeatedly.
- **Adaptive Quiz Scoring Integrity**: Corrected scoring logic for skipped questions, guaranteeing that evaluation counts and final scores remain completely accurate.
- **Bilingual Consistency**: Unified all action labels and confirmation dialogs across English (`en-US`) and Vietnamese (`vi-VN`).
