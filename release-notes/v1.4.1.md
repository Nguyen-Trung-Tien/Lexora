# Lexora v1.4.1 — Responsive Layouts & Data Protection
> Release Date: 2026-10-28 | Version: 1.4.1

## 🌟 Highlights
Version 1.4.1 refines button dimensions and text wrapping across all views to eliminate horizontal clipping on compact display resolutions, and integrates automated safety snapshots.

---

## ⚡ Improvements & UX
- **Responsive Width Budgeting**: Search boxes and action toolbars now adapt fluidly to small screen resolutions down to 1366x768 without text truncation.
- **Unified Interactive Cursor Feedback**: Consistent hand pointer cursors across all cards, buttons, and navigation elements.

---

## 🛠️ Bug Fixes & Stability
- **Pre-Update Automatic Snapshot**: Automatically captures a clean SQLite database snapshot before applying software upgrades.
