# Lexora v1.5.0 — Study Planner & Fluent 2 Polish
> Release Date: 2026-11-03 | Version: 1.5.0

## 🌟 Highlights
Lexora v1.5.0 introduces the **Study Planner Foundation** for managing daily study commitments and standardizes all application dialogs to 16px corner radii for a modern Windows 11 feel.

---

## 🚀 New Features
- **Study Planner Workspace**: Set daily target vocabulary counts, track countdown deadlines, and monitor your overall exam readiness progress.
- **Daily Study Streak Tracker**: Encourages consistent study habits with automatic streak counting and motivational milestones.

---

## ⚡ Improvements & UX
- **Fluent 2 16px Uniform Corner Radius**: Standardized all modal dialogs and cards for a cohesive, polished look.
- **Enhanced Visual Contrast**: Refined text color hierarchies to reduce eye strain during extended study sessions.

---

## 🛠️ Bug Fixes & Stability
- **SQLite Database Integrity Verification**: Added header validation checks before and after database backups to safeguard local data.
